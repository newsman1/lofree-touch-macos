# Changelog

## 0.4.2 — Initial experimental public release

- Decode the verified Lofree Touch Bluetooth side-button reports without a driver.
- Save button order and customizable click, double-click and hold actions.
- Offer menu-bar operation, login launch and automatic connection retries.
- Provide optional Mac Mouse Fix button 4/5 bridging.
- Match the verified device profile without requiring a pre-open mouse-collection check.
- Include source, tests, generated app artwork, setup and troubleshooting documentation.

Known limits include exact-profile compatibility, ad-hoc signing/permission renewal, hardcoded system-shortcut presets, limited Fn recording, and unverified wider gesture/hardware compatibility.
